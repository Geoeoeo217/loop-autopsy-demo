# loop-autopsy demo page

**Live page: https://geoeoeo217.github.io/loop-autopsy-demo/**

The one-minute demo page for [loop-autopsy](https://github.com/Geoeoeo217/loop-autopsy), a Jupyter extension that stops loops that can never end and shows which variable caused it.

The page includes a 41-second narrated demo video ([media/loop-autopsy-demo.mp4](media/loop-autopsy-demo.mp4)).

Try the package:

```bash
pip install loop-autopsy
```

Then run this in the first cell of a notebook:

```python
%load_ext loop_autopsy
```
