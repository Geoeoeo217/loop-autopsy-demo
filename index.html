Infinite-loop checker for Jupyter notebooks

loop-autopsy watches each loop while it runs, stops one that can never end and shows which variable caused it. Free for Python 3.9 to 3.13.

Eight kinds of endless loop. Correct loops run untouched.

Checks every loop while it runs

Each loop gets a few cheap checks per round, about 0.1 to 0.3 µs. It stops only with proof.

Names the variable that broke

Each report names the variable, shows its last values and gives one fix, such as count += 1.

homework.ipynb
[6]:
i = 10 while i > 0: i += 1
Loop autopsy — loop moving the wrong way (line 2) while i > 0: The loop stops when `i > 0` becomes False, which needs `i` to reach 0. But over the last 500 checks `i` went from 10 to 510, moving further away from 0 every time. Last rounds checked: round i ----- --- 496 505 497 506 498 507 499 508 500 509 501 510 Hint: Check the line that updates `i`: should it go the other way (for example `-=` instead of `+=`)?

Guards memory and time

It stops a loop before the kernel runs out of memory and warns early when a loop will pass 60 s.

homework.ipynb
[7]:
%autopsy config time_limit=120
time_limit = 120.0
[8]:
%autopsy reset
Settings are back to their defaults: time_limit 120.0 -> 60.0
[9]:
%autopsy
loop-autopsy is ON. Settings: time_limit 60.0 estimate_after 5.0 direction_after 500 jump_after 100 growth_after 2000 memory_stop 0.85 memory_warn 0.75

Catches runaway recursion

A function that calls itself with the same argument is caught, with its first and last calls side by side.

homework.ipynb
[10]:
def f(n): return f(n) f(3)
Loop autopsy — recursion stuck on the same arguments (line 1) def f(n): `f` kept calling itself (991 nested calls) until Python stopped it with `RecursionError`. Every call received exactly the same arguments (`n = 3`), so no call is any closer to the base case than the first one. First and last calls: call n (same) ---- -------- 1 3 2 3 3 3 989 3 990 3 991 3 Hint: The recursive call must pass a changed value, for example a smaller number or a shorter list, so that the base case is eventually reached.

Two lines to install

Run pip install loop-autopsy in a terminal, then %load_ext loop_autopsy in the first cell. Every loop after that is watched.
